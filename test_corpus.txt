# test_corpus.txt
#
# Attic Greek TTS Test Corpus — v2
#
# Organized by phonetic feature under test. Each section isolates one or two
# things so analysis.py spectrograms give clean, attributable results.
#
# Design principles:
#   - Use REAL Attic Greek words only. No fabricated forms (CLTK produces
#     garbage IPA on non-words, making spectral comparison meaningless).
#   - Minimal pairs use attested forms that differ in the target feature.
#   - Sections that test prosodic phenomena (downdrift, clause reset) use
#     sentences long enough for the effect to develop (~5+ words).
#   - Each section should be runnable independently via sections_to_generate.
#   - Comments start with #, stripped by load_sections.
#

# clusters on spectrogram.
# Words chosen: CVC or CVCV, all acute, minimal consonant interference.
# ============================================================================

νόησον τοίνυν, ἣν δ᾽ ἐγώ, ὥσπερ λέγομεν, δύο αὐτὼ εἶναι, καὶ βασιλεύειν τὸ μὲν νοητοῦ γένους τε καὶ τόπου, τὸ δ᾽ αὖ ὁρατοῦ· ἵνα μὴ οὐρανοῦ εἰπὼν δόξω σοι σοφίζεσθαι περὶ τὸ ὄνομα. ἀλλ᾽ οὖν δύο ταῦτα εἴδη ἔχεις, ὁρατόν, νοητόν; ἔχω. ὥσπερ τοίνυν γραμμὴν δίχα τετμημένην λαβὼν ἄνισα τμήματα, πάλιν τέμνε ἑκάτερον τὸ τμῆμα ἀνὰ τὸν αὐτὸν λόγον, τό τε τοῦ ὁρωμένου γένους καὶ τὸ τοῦ νοουμένου, καί σοι ἔσται σαφηνείᾳ καὶ ἀσαφείᾳ πρὸς ἄλληλα, ἐν μὲν τῷ ὁρωμένῳ τὸ μὲν ἕτερον τμῆμα εἰκόνες· λέγω δὲ τὰς εἰκόνας πρῶτον μὲν τὰς σκιάς, ἔπειτα τὰ ἐν τοῖς ὕδασι φαντάσματα καὶ ἐν τοῖς ὅσα πυκνά τε καὶ λεῖα καὶ φανὰ συνέστηκεν, καὶ πᾶν τὸ τοιοῦτον, εἰ κατανοεῖς. τί δ᾽ οὔ; ἆρα δὴ ὁρατόν, νοητόν;
