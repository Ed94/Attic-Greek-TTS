# test_corpus.txt
#
# Attic Greek TTS Test Corpus

# Organized by phonetic feature under test. Each section isolates one or two
# things so analysis.py spectrograms give clean, attributable results.
# Sections are numbered for stable reference across runs.
#
# Conventions:
#   - One Greek passage per line (no blank lines within a section)
#   - Sections separated by blank lines
#   - Comments start with #
#
